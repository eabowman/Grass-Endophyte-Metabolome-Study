G045.Field.data.csv
-------------------
Sample.no: Host sample name	
Site: Sample site name
Genus: Host grass genus
Epithet: Host grass species epithet
Species: Host grass species name
Species_final_nov24: Host grass species name
Native.status: Native status based on Lady Bird Johnson Wildflower Center and USDA plants
native.status.fine:	Fine native status
lat: latitude
long: longitude
collection.date: Date plant samples were collected
site.notes:	Notes on sites
slants.with.growth:	Slants with fungal growth out of the total.slants number
total.slants: Total culture slants per individual for CB dataset
SampleID: Internal host sample name	
metabolite_richness: Richness of overall metabolome

G045.TaxonomicData_CultureBased.csv
-----------------------------------
Sample.name: Individual culture name
sample.no: Host sample name	
SampleID: Internal host sample name	
Region: ITS sequence region	
Sequence:	
OTU.tbas: TBAS OTU classification based on 95% sequence similarity with ITS1, ITS2, and LSU	
OTU.fullsequence: classification based on 95% sequence similarity with the entire sequence	
OTU.ITS: classification based on 95% sequence similarity with just ITS1 and ITS2	
Phylum: Fungal phylum classification
Class: Fungal class classification
Order: Fungal order classification
Family: Fungal family classification
Genus: Fungal genus classification
Trophic.mode: Trophic mode of fungal group from FunGuild
Guild: Guild from FunGuild

G045.TaxonomicData_CultureFree.csv
-----------------------------------
Otu: Culture-free OTU name; classification based on 95% sequence similarity
Phylum: Fungal phylum classification
Class: Fungal class classification
Order: Fungal order classification
Family: Fungal family classification
Genus: Fungal genus classification
Database: TBAS or UNITE
likelihood.weight: Contains a confidence score generated by TBAS

G045_features_quantification_table.csv
-----------------------------------
row ID: unique ID assigned to eac unique metabolite feature 
row m/z: metabolite feature mass spectrometer mass(m) to charge (z) ratio
row retention time: metabolite feature liquid chromatography column retention time
columns D-A: integrated relative ion abundance from chromatograms of each metabolite feature in the samples

G045_canopus_formula_summary.csv
-----------------------------------
Chemotaxonomic structure annotations by SIRIUS NPclassifier and Classyfire on SIRIUS v6.3.0
mappingFeatureId: same unique ID assigned to each unique metabolite feature as 'row ID' in G045_features_quantification_table.csv
see SIRIUS documentation online for descriptions of data in other columns: https://v6.docs.sirius-ms.io/quick-start/

G045_structure_identifications.csv
-----------------------------------
Metabolite feature structural formulae elucidations performed by SIRIUS v6.3.0
mappingFeatureId: same unique ID assigned to each unique metabolite feature as 'row ID' in G045_features_quantification_table.csv
see SIRIUS documentation online for descriptions of data in other columns: https://v6.docs.sirius-ms.io/quick-start/

G045_20k_20221117.selfloop
-----------------------------------
Cosine scores for CSCS structural similarity of metabolite features between and within all SampleIDs 
(these data were not used in downstream analyses, but are included in each metabolome #####.Rdata object above)

G045_v2_metabolmes_total_20251018.csv
-----------------------------------
row.ID: unique ID assigned to eac unique metabolite feature 
row.m.z: metabolite feature mass spectrometer mass(m) to charge (z) ratio
row.retention.time: metabolite feature liquid chromatography column retention time	
smiles: (Simplified Molecular Input Line Entry System) text strings that describe the predicted chemical structure of each metabolite feature detected
NPC.pathway: biochemical pathway of origin metabolite feature annotation elucidated by NPclassifier
NPC.superclass: chemotaxonomic hierarchical rank 'superclass' for each metabolite feature annotation elucidated by NPclassifier
NPC.class: chemotaxonomic hierarchical rank 'class' for each metabolite feature annotation elucidated by NPclassifier
ClassyFire.most.specific.class: most specific metabolite feature class annotation elucidated by Classyfire
columns I-AR: integrated relative ion abundance from chromatograms of each metabolite feature in the samples
